# Ming Gao · Personal homepage template

Buildless HTML/CSS/JavaScript, compatible with GitHub Pages. Open `index.html` directly to review. No dependencies or external fonts.

## Content and editing

- Edit English content directly in `index.html`; matching Chinese content is in each element's `data-zh` attribute.
- The language button switches the main page copy; proper names and publication titles stay in English.
- Update colors and typography in the `:root` and CSS rules.
- The abstract speech illustration is decorative, not an experimental result. A portrait can replace it after the owner selects one.
- No phone number, private resume attachment, or invented paper links are included.
- Full author lists, verified paper URLs, public CV downloads and a chosen portrait are pending content review.
- Internship dates are deliberately omitted for iFLYTEK until the owner confirms the public date range.
- The EMNLP 2026 entry follows the supplied CV; verify the final bibliographic information before final publication.

## GitHub Pages

The root `index.html` can be served directly by GitHub Pages. In repository Settings → Pages, choose Deploy from a branch, `main`, `/(root)`, then Save. This template does not change Pages settings automatically.

## Validation

Verify anchor targets, local links, JavaScript syntax, and content before committing. Layout includes mobile breakpoints and reduced-motion support. Browser visual QA is still required.
